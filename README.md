# scriptyyy

Скрипты по ВИЭ / энергорынку Казахстана (без выгруженных данных).

## Папки

| Папка | Описание |
|---|---|
| `ВИЭ_координаты/` | Координаты объектов ВИЭ с rfc.kz → Excel |
| `индексация_тарифов/` | Индексация тарифов ВИЭ 2021–2026 → Excel |
| `KEGOC_БРЭ/` | Парсер БРЭ KEGOC |

Данные и Excel генерируются локально при запуске скриптов.
